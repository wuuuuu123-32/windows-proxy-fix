# 代理残留修复工具（Windows）

> **只想拿来用？** 到 [Releases](../../releases/latest) 下载 zip，解压后双击 `fix-proxy.bat` 就行，
> 不必看下面的原理说明。

代理软件（Clash / Clash for Windows / Clash Verge / mihomo / v2rayN / sing-box …）
在**断电、强制关机、崩溃、蓝屏**之后没能正常退出，会在系统里留下收不回去的代理设置。
典型症状：

- 所有网页都打不开，**把代理软件关掉也没用**
- 网页能正常打开，但**某个程序一直连不上服务器**（游戏客户端、下载器、桌面应用）
- 明明没开代理，程序却提示「网络错误 / 无法连接服务器 / 检测到代理」

这个工具用一次点击把这些残留清干净。

## 为什么会这样

Windows 里有**两套互不相干**的代理设置：

| | 谁在用 | 在哪改 |
|---|---|---|
| **WinINET** | 浏览器、Internet 选项里看到的那一套 | 「设置 → 网络和 Internet → 代理」 |
| **WinHTTP** | 浏览器以外的绝大多数程序 | 只能在命令行改，图形界面看不到 |

代理软件崩溃时经常只清掉了其中一套，甚至一套都没清掉 —— 所以会出现
**「网页正常，但别的程序连不上」**这种看起来矛盾的现象。

更隐蔽的是：光把开关关掉还不够。**代理地址**、以及「Internet 选项 → 连接 → 局域网设置」
里的那几个勾选（存在注册表的**二进制值**里，图形界面之外看不到），都可能继续残留，
被应用当成「当前有代理」而拒绝直连。

## 使用方法

1. 下载 [Releases](../../releases/latest) 里的 zip（或 `git clone` 本仓库），解压到任意文件夹，**确保这两个文件在同一个目录里**：
   - `fix-proxy.bat`
   - `fix-proxy.ps1`
2. 双击 `fix-proxy.bat`
3. 弹出「你要允许此应用对你的设备进行更改吗？」时点 **是**（重置 WinHTTP 需要管理员权限）
4. 跟着窗口里的中文提示走，看到提示按回车
5. 结束后**重启一次电脑**，再打开之前连不上的程序

命令行方式（可选）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\fix-proxy.ps1
```

只想看诊断结果、不改任何设置：加 `-DryRun`

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\fix-proxy.ps1 -DryRun
```

## 它做了什么

1. 检查是否还有代理软件在运行
2. 检查并清理 **WinINET**：代理开关、残留的 `127.0.0.1:端口`、PAC 脚本地址、自动检测设置
3. 取消「Internet 选项 → 连接 → 局域网设置」里残留的勾选（含注册表二进制值里的位）
4. 通知系统立即刷新，不用重启就生效
5. 显示并重置 **WinHTTP** 代理（需管理员权限）
6. 刷新 DNS 缓存
7. 检查网卡上有没有残留的代理 DNS（如 `198.18.x.x`）
8. 检查代理软件留下的虚拟网卡（TUN 模式残留）
9. 检查默认路由和 `198.18.x.x` fake-ip 路由残留
10. 检查 hosts 文件有没有可疑记录
11. 测试网页和 TCP 连通性
12. 网页本身也不通时，可选重置网络堆栈（`winsock` / `int ip`，需要重启）

## 它不会做什么

- 不修改、不删除任何个人文件
- 不安装、不下载任何东西
- 不碰你的代理软件本体和订阅配置
- 不会自动执行「深度修复」——那一步必须手动输入 `Y` 才会跑

## 关于「网络诊断报告.txt」

运行结束后，会在**桌面**生成一份「网络诊断报告.txt」，记录本次的全部检查结果。
如果修完还是不行，把这份报告发给帮你排查的人，能省很多来回。

（报告是追加写入的，多次运行会保留历史记录。）

## 常见问题

**Q：为什么网页正常，游戏/软件却连不上？**
A：因为那两套代理设置是分开的。浏览器用 WinINET，其它程序多半用 WinHTTP ——
本工具两套都会清。

**Q：点了「是」UAC 之后还是不行？**
A：先重启电脑。虚拟网卡状态、反作弊驱动、网络栈都需要重启才彻底复位。

**Q：会不会把我公司的代理设置弄坏？**
A：不会。只有当代理地址指向**本机**（`127.0.0.1` / `localhost` / `0.0.0.0`）时才会清除；
指向其它地址（单位/校园网代理）时脚本会保留并提示。

**Q：提示「本机不允许读取网卡信息」，跳过了几步？**
A：那是权限受限的环境（例如在受限令牌下运行）。跳过的只是**只读的诊断步骤**，
不影响实际修复。

**Q：杀毒软件报警？**
A：脚本本身不做任何可疑操作，但它会改注册表、重启网络服务，个别杀软会提示。
源码就在仓库里，可自行审阅。

## 系统要求

- Windows 10 / 11（Windows 8.1 也可，只要能跑 PowerShell 5.1）
- 系统自带的 Windows PowerShell，无需安装任何东西
- 重置 WinHTTP 那一步需要管理员权限（会弹 UAC）
